# 民法典生活伴侣 · Civil Code Companion

> 把《中华人民共和国民法典》变成可对话的 Agent Skill —— **生活纠纷一句话，条文对号入座。**

一个自带全文数据的 Agent Skill（`SKILL.md` 规范）。用户用大白话描述一个生活纠纷，它输出四段：**涉及编章 → 核心条文（精确条号）→ 大白话解读 → 下一步建议**。

**离线可用**：不联网、不要 API Key、不要数据库、不依赖任何 MCP。拷进 skills 目录即可工作。

---

## 它解决什么问题

法律 AI 最要命的是**条号幻觉**——模型一本正经地说"根据《民法典》第 1234 条"，而第 1234 条根本是另一回事。

本技能的做法是：**不给模型自由发挥的空间**。

- 民法典全文 **1260 条**（7 编 + 附则，逐字取自官方公布文本）随包分发
- 另附 **338 条高频条文**按 11 类生活场景分组——先查速查表，未命中再查全文
- 硬约束写进技能：**禁止凭记忆写条文原文**，凡给出原文的必须来自 `references/` 下的文件
- 查不到就写"未找到"，**禁止编造条号**

## 目录结构

```
civil-code-companion/
├── SKILL.md                        技能主体（触发描述、执行步骤、禁止事项、对话示例）
├── references/
│   ├── 生活高频条文速查.md           338 条高频条文，按 11 类生活场景分组（优先查）
│   └── 民法典全文.md                 民法典全文 1260 条，含编/章分组与附则
├── mcp.example.json                可选：民法典全文 MCP 配置示例
├── README.md
└── LICENSE
```

## 安装

把整个文件夹（至少含 `SKILL.md` 与 `references/`）放进目标客户端的 skills 目录：

| 客户端 | 路径 |
|---|---|
| WorkBuddy | `~/.workbuddy/skills/civil-code-companion/` |
| Claude Code / Claude Desktop | 对应的 skills 目录 |
| 豆包（PC 客户端） | 工作模式 → 技能·连接器·伙伴 → 我的技能 → 上传技能（zip 或文件夹） |

技能靠 `description` 字段自动触发。说 **"民法典"、"第X条"、"房东不退押金"、"遗产怎么分"、"狗咬人谁赔"** 等都会命中。

## 覆盖范围

| 编 | 条文范围 | 典型场景 |
|---|---|---|
| 第一编 总则 | 1–204 | 诉讼时效、行为能力、见义勇为、代理 |
| 第二编 物权 | 205–462 | 房产产权、业主共同决定、相邻关系、抵押 |
| 第三编 合同 | 463–988 | 租房押金、二手房买卖、借钱不还、定金、违约 |
| 第四编 人格权 | 989–1039 | 名誉、肖像、隐私、个人信息泄露、性骚扰 |
| 第五编 婚姻家庭 | 1040–1118 | 离婚财产、夫妻共同债务、彩礼、抚养费、家暴 |
| 第六编 继承 | 1119–1163 | 遗嘱、法定继承顺序、遗产分割、父债子还 |
| 第七编 侵权责任 | 1164–1258 | 宠物咬人、高空抛物、商场摔伤、交通事故 |
| 附则 | 1259–1260 | 术语含义、施行日期与旧法废止 |

**明确不处理**：劳动争议（走劳动仲裁 12333）、行政处罚、刑事定罪量刑、税务、诉讼程序细节。

## 效果示例

| 输入 | 输出 |
|---|---|
| "房东说房子卖了让我月底搬走，合同还剩 8 个月" | 第三编 · 第十四章 租赁合同 → 第 725 条（买卖不破租赁）+ 第 577 条 → 新房东须继续履行 → 留证据、书面主张、强行清退则报警并索赔 |
| "我爸去世没留遗嘱，房本是爸妈两人的名字" | 第六编 · 第 1123/1127/1153/1161 条 → 先析产一半归母亲，余下按第一顺序继承 |
| "邻居偷了我快递，能判几年？" | 超出民法典范围 → 建议报警；物权视角可主张返还原物（第 235 条） |

## 常见误区纠偏（技能内置）

- 「净身出户」**没有**法律依据（1087 + 1091）
- 离婚冷静期**只适用协议离婚**（1077）
- 「退一赔三」「假一赔十」**不是**民法典条文，出自消费者权益保护法、食品安全法
- 民间借贷「LPR 四倍」出自**最高法司法解释**，不是民法典正文（680 只写禁止高利放贷）
- 公证遗嘱**不再天然优先**（1142）
- 「父债子还」不绝对——限定继承（1161）
- 未成年人大额打赏可主张返还（19 + 145）

## 数据来源与校验

- 条文取自《中华人民共和国民法典》官方公布文本（2020-05-28 通过，2021-01-01 施行）
- **1260/1260 条完整性已程序化校验通过**，无缺号、无残留 HTML 标签、无占位符
- 其中第 400、708 条在原数据源中被 HTML 残渣粘连，已剥离修复；第 1259、1260 条（附则）原数据源缺失，已按官方文本补齐
- 上述 4 条均经**多源交叉核对**（最高人民检察院、广东省人民检察院、新疆维吾尔自治区人大常委会、泉州市司法局、青海 12348 法网等），逐字一致

## 可选增强：接入民法典 MCP

若运行环境支持 MCP，可额外接入 [@jjfather/civil-code-of-china-mcp](https://www.npmjs.com/package/@jjfather/civil-code-of-china-mcp)，用它的 `get_structure` / `get_article_content` 交叉校验条号与原文。

把 `mcp.example.json` 的内容合并进客户端的 MCP 配置：

```json
{
  "mcpServers": {
    "civil-code-of-china": {
      "command": "npx",
      "args": ["-y", "@jjfather/civil-code-of-china-mcp"]
    }
  }
}
```

需要本机装 Node.js。**注意**：这是 `stdio` 型本地服务，网页版 / 手机 App 用不了；纯云端环境（如豆包云电脑）也调不到——**但这些场景不下 MCP 也能用**，因为全文已在 `references/` 里。
